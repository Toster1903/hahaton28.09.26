# Рекомендация элективных дисциплин МГПУ

`recommend.py` обучает модель ранжирования и записывает пять доступных дисциплин для каждого студента тестовой выборки в `submission.csv`.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python recommend.py
```

Исходный архив лежит в `data/selection_formula.zip`. Его можно заменить через `--archive`, путь к результату — через `--output`. Для быстрого повторного обучения без локальной проверки используйте `--skip-validation`. Число итераций задаётся через `--iterations`.

## Как работает решение

Для каждой пары «студент — доступная дисциплина» скрипт считает признаки из профиля, истории выбора, популярности дисциплины в прошлых периодах и сходства текстов дисциплин с историей студента. `CatBoostClassifier` обучается на выборах второго и третьего периодов. Положительные примеры получают веса по приоритету из официальной метрики. При обучении берутся все выбранные дисциплины, наиболее популярные и случайные остальные кандидаты; при прогнозе ранжируются **все** доступные дисциплины.

Локальная проверка откладывает 20% студентов из разметки третьего периода и печатает pNDCG@5 на этой группе. Затем модель переобучается на всех доступных ответах и формирует прогноз четвёртого периода. Значение на отложенной части третьего периода служит ориентиром и не гарантирует такого же результата на четвёртом.

`submission.csv` содержит ровно одну строку на студента и пять различных идентификаторов из его `available_modules`.
