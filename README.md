# Персональные рекомендации элективов МГПУ

Решение и проверенный `submission.csv` находятся в этой папке. Главный скрипт — `recommend.py`, признаки — `features.py`, подробный аудит — `AUDIT.md`.

На контрольных 600 студентах: **pNDCG@5 = 0,52595**, исходное решение при одинаковом обучающем разбиении: **0,44268**. Это локальная оценка третьего периода. Сообщённый Public предыдущего файла: **0,3086987554**; Public нового файла пока неизвестен. Проверка на новом учебном периоде значительно сложнее случайного разбиения студентов.

## Запуск

Проверено на Python 3.14.4. Зависимости зафиксированы в `requirements.txt`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python recommend.py --predict-only
```

Команда использует сохранённые модели из `models/` и заново создаёт `submission.csv`. На macOS для LightGBM нужен OpenMP: `brew install libomp`, если библиотека ещё не установлена.

Полное переобучение на данных архива:

```bash
.venv/bin/python recommend.py
```

Доступны `--archive`, `--output`, `--model-dir`. Архив читается напрямую из `data/selection_formula.zip`. При `--predict-only` проверяется совпадение архива с тем, на котором обучены модели.

## Метод

Обучение проходит на всех доступных парах «студент — дисциплина» второго и третьего периодов. Цель — ожидаемая полезность выбора с весами приоритетов из официальной метрики. Это ранжирующий балл, а не откалиброванная вероятность.

Ансамбль LightGBM состоит из двух моделей: 25% базовой модели и 75% модели с переносом популярности от похожих по тексту курсов. Дополнительные признаки описывают профиль студента, историю и повторяемость выбора, связи курсов, текстовое сходство, доступность и популярность в предыдущих периодах. Частоты учитывают, в каких периодах курс действительно предлагался.

Для студента без истории и профиля применяется сглаженная популярность предыдущего периода. Если уже есть наблюдения предыдущего периода для студентов с пустым профилем, они учитываются со сглаживанием к общей популярности. Финальное обучение использует все предоставленные ответы третьего периода; скрытых ответов четвёртого периода в исходных файлах нет.

Официальная `metric.py` считает ограниченный сверху единицей взвешенный DCG с нормировкой на один идеальный первый выбор. Эта реализация отличается от обычного NDCG с IDCG всех пяти релевантных курсов. Оригинал сохранён без изменений в `vendor/metric.py`.

## Воспроизведение проверок

```bash
.venv/bin/python audit_data.py
.venv/bin/python verify_submission.py
.venv/bin/python vendor/metric.py --solution audit/validation_solution.csv --submission audit/validation.csv
```

Для повторного обучения двух моделей на аудиторском разбиении:

```bash
.venv/bin/python audit_experiments.py --tag mixed_full_soft --model soft --drop content_global_rate,content_recent_rate,content_institute_rate,content_specialty_rate,smoothed_global_rate,smoothed_institute_rate,smoothed_specialty_rate,course_age
.venv/bin/python audit_experiments.py --tag mixed_content --model soft
.venv/bin/python audit_select.py
.venv/bin/python audit_evaluate.py
```

Кэш признаков в `work/` проверяется по SHA-256 архива и исходного кода построителя признаков. Контрольные 600 студентов исключены из обучения и ранней остановки; 608 других студентов используются для выбора числа деревьев и веса ансамбля. На контрольной группе просматривались результаты нескольких вариантов: она не заменяет полностью независимый скрытый тест.

Для исходной модели используется `requirements-audit.txt` и `audit_reproduce_original.py`. Исходный код и предыдущий файл сохранены в `audit/`. Файлы JSON в `audit/` содержат результаты отдельных экспериментов; `audit/final_comparison.json` — итоговое сравнение и парный bootstrap.

## Состав

- `recommend.py`, `features.py` — рабочий конвейер обучения и рекомендаций.
- `models/` — обученные модели и манифест с версиями и хешем данных.
- `submission.csv` — 4306 строк, по пять различных доступных курсов.
- `AUDIT.md`, `audit/` — выводы, проверочные предсказания, метрики и исходный файл с сообщённым Public.
- `audit_data.py`, `audit_experiments.py`, `audit_select.py`, `audit_evaluate.py` — воспроизводимые проверки.
